# NSE Assistant brand assets

Generated using the built-in imagegen tool, then prepared into matching web sizes with macOS sips. The selected original is `logo-source.png`; `logo-square.png` trims the unused outer black canvas for a readable small icon. Production sizes and the ICO/manifest live under `ui/assets/`. The logo background and app theme are pure black.

Final generation prompt:

> Production app icon, minimal vector-style logo on a perfectly solid pure black #000000 square background. Draw one precise, bold white geometric N monogram using two vertical rectangular pillars joined by a rising diagonal band, like a systematic trading signal. Clean filled flat shapes with mathematically straight edges, uniform pure white interiors, absolutely no texture or distressing, no grain, scratches, speckles, cutouts or holes. Center it, leave a generous 15% black margin around it. Strong silhouette readable as a tiny 16 pixel favicon. No letters other than the monogram, no wordmark, no border, no mockup, no lighting, no shadow, no gradients, no bevels. Original independent finance-research application identity, premium and restrained. Deliver a single square flat graphic.

Earlier transparent drafts were discarded; no API fallback was used. This artwork is an independent application identity and does not represent exchange affiliation. The favicon and installed-app icons use the same generated artwork as the sidebar logo.
