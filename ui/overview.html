What these totals include

Legacy trades without saved charge breakdowns are estimated from their recorded fills using the existing paper cost model. Stored trade results stay unchanged.

Closed outcomes are shown by entry-session date using the latest recorded final result. This is a date-based review, not an intraday point-in-time replay.

Open estimates use fresh marks for the current session and include a hypothetical exit. Historical open positions and missing execution paths stay unresolved.

Cloud, LLM and data subscriptions are excluded from trading charges. Estimates are not broker contract notes. Dhan pricing reference ↗
